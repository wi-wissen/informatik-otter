Bei der großen Flut hat Benny Biber sein Hab und Gut verloren – außer einer Bürste. Diese will er nun gegen einen anderen Gegenstand eintauschen, den er dann wiederum eintauschen will, usw. Sein Ziel ist es, mit mehrmaligem Tauschen zu einem Haus zu kommen. Benny hat die folgenden Tauschangebote im Bibernet gefunden. Zum Beispiel möchte Anna für eine Bürste einen Ballon geben.

| Name | nimmt | gibt dafür |
|---|---|---|
| Anna | Bürste | Ballon |
| Bert | Bürste | Korb |
| Claudia | Ballon | Boot |
| Daniel | Boot | Motorrad |
| Emil | Ballon | Fahrrad |
| Franziska | Korb | Boot |
| Gustav | Korb | Hund |
| Helen | Hund | Ballon |
| Ivo | Fahrrad | Ballon |
| Jeanine | Hund | Teppich |
| Klaus | Teppich | Motorrad |
| Lili | Gemälde | Teppich |
| Monika | Fahrrad | Motorrad |
| Norbert | Teppich | Haus |

**Wie kann Benny mit mehrmaligem Tauschen zu einem Haus kommen?** Wähle passende Tauschangebote und bringe sie in die richtige Reihenfolge.
